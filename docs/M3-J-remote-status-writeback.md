# M3-J 远程任务状态写回

## 变更

- 后端新增移动端 `POST /api/v1/automation/mobile/tasks/{id}/status`。
- 客户端将领取后的运行、人工暂停、继续、完成、失败和停止映射到后台任务状态。
- 状态请求和断点/用户记录共用异步重试队列，最多重试三次，不阻塞无障碍状态机。
- 同一状态和错误签名在客户端去重，避免页面观察事件造成重复写回。
- 移动端只能写入运行中、暂停、完成、失败、取消，不能绕过后台任务状态流转写入草稿或待执行。

## 安全边界

状态写回失败不会改变本地执行结果；本地诊断记录仍是当前运行的事实来源。授权失效、任务状态冲突或人工接管要求会保留在本地并显示在诊断状态中。

## 验证

- 后端任务接口覆盖领取后暂停/继续状态写回。
- Android JVM 单元测试、Lint、Debug APK 和 instrumentation APK 构建通过。
