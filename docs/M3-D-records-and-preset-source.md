# M3-D 任务历史与预设搜索词来源

## 已实现

- 任务运行结束、暂停、停止或失败时，保存任务摘要：任务名称、搜索词数量、处理/跳过/屏蔽/重复计数、状态和更新时间。
- 任务记录页展示历史任务摘要，并保留当前任务的逐用户结果记录。
- 摘要不保存用户名称、抖音号或 OCR 原文；逐用户记录只保留匿名 identity hash。
- `SearchPresetRemoteSource` 定义远程预设接口边界。
- `CachedSearchPresetRepository` 实现远程优先、24 小时本地缓存、网络失败使用过期缓存、无缓存时回退内置预设。
- `SharedPreferencesSearchPresetCache` 负责 Android 私有目录中的 JSON 缓存。

## 当前边界

M3-D 尚未绑定具体后端 URL 或鉴权协议，因此界面默认使用内置预设。后端接口确定后，只需注入 `SearchPresetRemoteSource`，任务快照仍会固定最终搜索词和预设版本，不会在任务执行中被远程更新改变。

## 验收重点

1. 完成或暂停一项任务后，进入“记录”页能看到任务摘要。
2. 重新打开 App 后，历史摘要仍存在。
3. 远程预设请求失败时，已有缓存或内置预设仍能生成任务。
4. 任务执行使用创建时的搜索词快照，不受后续预设刷新影响。
