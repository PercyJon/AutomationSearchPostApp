# M7-C2c：用户选择阶段纯路由拆分

日期：2026-08-24
范围：`DouyinNavigationController.selectVisibleUser()` 的入口优先级，不改变候选行处理动作。

## 变更前记录

- 现象：`selectVisibleUser()` 同时承载处理上限、远程断点续接、账号帮助页结束判断，以及后续节点/OCR/几何/点击和检查点写入；入口优先级不便于独立回归。
- 稳定复现步骤：以处理上限已达、远程续接待定位、账号帮助仅剩提示行、或带视口锚点的用户结果页调用该阶段。
- 预期行为：保持既有优先级——处理上限 → 无锚点的远程续接 → 无锚点的账号帮助结束 → 候选行选择；带视口锚点时继续既有续接选择。
- 实际差异：本轮为等价重构，没有线上故障；原优先级散落在副作用方法开头，缺少纯函数测试。

## 单一假设与最小修改

假设：把入口优先级抽为无副作用路由，可在不改变实际自动化动作的条件下锁定行为等价性。

- 新增 `UserSelectionFlowRouter` 和不可变 `UserSelectionFlowState`，只输出四种既有分支。
- 控制器保留账号帮助文本检查的时机，以避免在处理上限、远程续接或视口锚点场景新增页面读取。
- 控制器继续负责远程锚点定位、下一查询、完成记录、节点优先/OCR辅助/几何校验、点击、手势和检查点。

## 验证结果

- `UserSelectionFlowRouterTest` 覆盖：处理上限最高优先级、远程续接优先于账号帮助、账号帮助结束、视口锚点续接和普通选择。
- 自动化验证：`./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug` 与 `git diff --check` 通过。
- 真机 OnePlus NE2210（`b33aa309` / Android 16）：安装更新后无障碍服务为 Bound/Enabled、`Crashed services` 为空；本轮仅做停止态服务健康确认，不启动任务、不进行页面操作、空白探测或消息发送。

## 几何与安全检查

- 未新增 Android 几何尺寸、固定 px、坐标或手势；无需新增 dp 归一化逻辑。
- 候选行选择保持节点优先、OCR 辅助、几何校验、页面确认与安全兜底的原有顺序。
