# M3-G 远程任务会话

## 变更

- 首页读取后台 `READY/RUNNING/PAUSED` 任务，并显示最多 5 个待执行任务。
- 领取后将后台数字任务 ID写入本地任务快照，控制器仍使用本地状态机执行。
- 用户结果和稳定的结果视口通过 `RemoteTaskSyncQueue` 异步提交，单项最多重试三次。
- 网络错误、授权失效或队列拥塞只记录诊断状态，不阻塞本地自动化；本地记录仍是执行主状态。
- 远程任务即使配置为 `send`，本阶段也强制使用 M2 空白消息安全探测，不会自动发送真实消息。
- 远程任务领取时会读取后台权威进度；已有进度时先在用户结果页定位 `last_user_key`，定位成功后严格从下一行继续。
- 已有进度但后台没有 `last_user_key` 时，客户端会暂停并提示人工确认，不会从首屏开始重复处理。

## 当前边界

远程地区/屏蔽词目录到任务快照的完整绑定、后台任务状态写回、真实消息发送的二次人工确认和后端真机联调留在后续迭代。这样不会因网络状态或后台配置变化破坏当前已验收的无障碍链路。
