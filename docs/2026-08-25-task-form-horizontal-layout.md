# 任务表单横向布局与入口收敛记录

## 开始前记录

- 当前现象：B 端获客表单仍保留“基础信息 / 搜索条件 / 筛选条件 / 执行限制”分段大标题和顶部自动化服务状态；两张任务表单的字段标签与输入框上下排列，选择项的未选中/选中颜色及最小宽度也尚未统一。
- 稳定复现：登录后从首页依次进入“B 端用户私信”和“评论私信”创建页；评论页可看到“开始位置”及“当前用户主页 / 搜索指定用户”两项。
- 预期行为：B 端页标题为“新建 B 端获客任务”，评论页标题为“新建评论区私信任务”；字段采用左标签、右控件的紧凑行式布局；B 端移除四个分段标题及顶部服务状态，评论页固定为搜索指定用户并隐藏开始位置；服务状态只在“我的”页展示；选择项和按钮使用统一的 primary 蓝色状态。
- 实际差异：冗余分段和纵向标签增加了滚动距离，评论任务仍暴露当前用户主页入口，服务状态提示分散在任务表单中。
- 本轮唯一根因假设：问题来自表单展示组件和入口选择暴露过多，而不是任务草稿、校验或自动化状态机。
- 修改边界：只调整 `HomeScreen.kt` 和 `MyPage.kt` 的可视标题、字段布局、选择控件色彩以及评论表单入口展示；不修改任务模型、校验规则、保存/启动回调、无障碍、抖音识别、网络或后端逻辑。

## 验证计划

1. 运行格式检查、单元测试、lint 与 Debug 构建。
2. 在已连接真机依次检查 B 端表单、评论表单和“我的”页；只进行非执行型控件的展示/选择验证。
3. 不保存、挂起或启动任务，不调用抖音；结束后停止 App 并返回系统桌面。

## 实施结果

- 结果：**改善**。B 端表单移除了“基础信息 / 搜索条件 / 筛选条件 / 执行限制”四个分段标题，以及顶部自动化服务状态；页面标题改为“新建 B 端获客任务”。
- B 端字段改为左标签、右输入框的 50dp 横向行式布局；“自定义搜索词 / 屏蔽关键词 / 最多处理用户数”收敛为“搜索词 / 屏蔽词 / 用户上限”。
- 评论任务页面标题改为“新建评论区私信任务”；入口固定为搜索指定用户，隐藏了“开始位置”和两个入口选择，并删除“任务配置”标题与当前用户主页专用的挂起按钮。
- 评论字段、匹配方式、开关和数值限制均采用相同的行式布局；“评论匹配词 / 视频数上限 / 每个视频用户数”收敛为“匹配词 / 视频上限 / 每视频人数”。
- 预设词与匹配选择项设置为最小 72dp 宽、34dp 高：未选中为白底蓝字蓝框，选中为蓝底白字；保存按钮为白底蓝字蓝框，立即开始按钮为蓝底白字。
- 自动化服务状态移至“我的”页，在授权状态下方统一展示。任务草稿、校验、保存、立即开始、自动化状态机、无障碍、抖音识别和网络逻辑均未改动。
