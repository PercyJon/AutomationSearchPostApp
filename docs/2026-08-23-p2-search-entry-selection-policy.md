# 2026-08-23：P2-G2 搜索入口选择策略抽取

本记录遵循项目根目录 `AGENTS.md` 的小步修改与同路径验证要求。

## 当前差异

- 现象：控制器内直接编排搜索入口的语义节点、结构节点和受限比例兜底优先级。
- 稳定复现：搜索入口可能具有语义标签，也可能只暴露受限区域内的无标签可点击图标；任何比例兜底只能在两类节点均失败后使用。
- 预期：保留语义节点优先、结构节点次之、最后受限比例兜底的顺序，且后置页面确认仍由控制器负责。
- 实际：选择优先级与搜索流程状态机混合，难以对三种分支独立回归。

## 本轮唯一根因假设

搜索入口的无副作用选择决策与动作、页面确认和暂停编排共处，削弱了安全优先级的可测性。

## 最小修改与验证

- 新增 `SearchEntrySelectionPolicy`，仅根据既有动作结果选择语义、结构或受限比例分支。
- 不改变任何选择器、节点点击、受限比例坐标、搜索关键词校验、后置确认或暂停逻辑。
- 风险：搜索入口分支顺序错误，可能过早进入受限比例兜底。
- 验证：三条优先级分支单测；完整 Debug 单测、Lint、构建；真机干跑。

## 验证结果

- 定向与完整检查：通过；`git diff --check` 无输出。
- 真机：OnePlus NE2210（Android 16 / SDK 36，设备序列号 `b33aa309`）；`designer`、匹配词“不错”、任一匹配、1 个视频 / 1 位用户、干跑。
- 已验证路径：语义节点打开搜索入口 → 关键词提交 → 语义用户标签 → `USER_RESULTS` 后置确认；未使用结构或受限比例搜索入口兜底。
- 用户行观察：当前结果首卡的无障碍树缺少结构化行，OCR 回退实际运行但返回 `NO_FOLLOW_LABEL`。两次同参数复现均按安全规则结束，未进入任何用户主页、私信或空白消息探测。该结果由当前页面缺少行证据触发，未修改、也不会为使回归通过而放宽安全门。
- 几何检查：未新增 Android 几何尺寸、固定 px 或手势；既有受限比例兜底的调用条件保持不变。
