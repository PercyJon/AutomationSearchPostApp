# 系统返回导航一致性修复记录

## 开始前记录

- 当前错误现象：从 B 端私信或评论私信任务表单按 Android 系统返回键，会直接离开 App；而页面左上角返回按钮可正确回到工作台。
- 稳定复现：登录后“首页 → B 端私信”或“首页 → 评论私信”，按设备系统返回键。
- 预期行为：系统返回键应与页面左上返回保持一致：关闭任务表单、任务详情或二级页并回到其父页面；只在首页才交由系统离开 App。
- 实际行为差异：当前 `AppHomeScreen` 仅有左上按钮状态回调，没有为 Compose 页面层级注册系统返回处理，因此系统直接结束 Activity。
- 本轮唯一根因假设：缺少 `BackHandler`，而非任务保存、导航状态或无障碍逻辑异常。
- 修改边界：只在 `AppHomeScreen` 添加基于已有 `showCreateTask`、`showCommentTask`、`detailTaskId` 和 `HomeSection` 的系统返回映射；不修改任务模型、自动化命令、页面内容或底部导航。

## 验证计划

1. 编译、单元测试和 Android lint。
2. 真机验证系统返回：任务表单 → 首页、任务详情 → 记录列表、记录/设置/诊断 → 我的、我的/待办 → 首页。
3. 不保存、启动、暂停、重试或诊断任务；测试结束后停止 App 并返回系统桌面。

## 实施结果

- 结果：**改善**。`AppHomeScreen` 新增一个系统 `BackHandler`，仅在当前页面存在应用内父级时拦截返回。
- 返回优先级：任务详情 → 记录列表；新建/评论任务表单 → 原工作台；记录/设置/诊断 → 我的；我的/待办 → 首页。
- 首页不注册拦截，因此仍保留 Android 的默认退出行为。未改变左上返回按钮、底部导航、任务表单、任务状态或自动化命令。

## 验证结果

- `./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug -PautomationApiEndpoint=<受管 HTTPS 服务地址>` 通过（55 个 Gradle 任务）；仅保留既有 Material/图标弃用警告。
- **真机 OnePlus NE2210 / b33aa309 / Android 16**：使用系统返回键验证 B 端私信 → 首页、评论私信 → 首页、任务详情 → 记录列表、记录列表 → 我的、设置 → 我的、诊断 → 我的、我的 → 首页、待办 → 首页，均按预期完成。
- 测试中未保存、启动、暂停、继续、停止、重试或采集诊断；未调用抖音；结束后 App 已停止并返回系统桌面。
