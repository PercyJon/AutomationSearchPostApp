# M3-K 稳定性与处理记录改造

## 本轮范围

1. 任务进入 `COMPLETED_TASK`、`FAILED`、`STOPPED` 或 `PAUSED_FOR_MANUAL_HANDOFF` 后，服务通过显式 Intent 将主界面切换到“记录”页。启动节流避免同一终态重复拉起 Activity；点击任务记录进入独立详情页。
2. `UserTaskRecord` 持久化显示名、稳定账号 key、消息/模拟内容、开始/结束时间、结果和原因；记录与任务摘要均可点击查看详情。
3. 识别用户列表中的“找不到想要的账号/告诉我们”辅助行。真实用户行存在时继续处理；只有辅助行时才允许走受限的结果结束/下一查询分支。
4. 私信入口只接受 Accessibility 节点语义。候选必须含“发私信/私信/message/paper/plane”等语义，且拒绝“客服/咨询/购物车/商品”。OCR 仅用于确认和诊断，不直接执行点击；无语义候选时安全重试后跳过或人工暂停。
5. ML Kit OCR 支持局部区域裁剪、低分辨率放大和坐标还原；页面探测按区域与节点签名短期缓存。OCR 驱动页面必须连续两帧一致后才推进。
6. 启动面兼容：抖音恢复到旧搜索结果时复用顶部真实 EditText 并重新校验关键词；用户列表、主页和聊天页走有界返回；检测到开屏广告只等待，不点击广告控件。无法确认的自定义页面仍进入人工接管，避免误点。

## 验收命令

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

真机仅使用 `adb install -r`、`adb logcat` 和截图检查；不运行会自动卸载 APK 的 Gradle connected test。

## 后续输入

`ImageMatcher` 已作为安全扩展点保留。只有在采集并脱敏确认真实设备的搜索、私信和发送图标模板后，才接入 OpenCV 实现，并要求模板置信度和页面语义双重确认。模板缺失或置信度不足时维持“节点优先、暂停/跳过”的安全策略。
