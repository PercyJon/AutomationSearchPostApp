# M7-C2g：用户选择阶段动作编排拆分

日期：2026-08-24
范围：用户结果选择入口的处理上限、远程锚点续接和账号帮助结束分派。

## 变更前记录

- 现象：用户选择纯路由已独立，但控制器仍直接分派处理上限、远程续接和账号帮助结束动作。
- 稳定复现步骤：以用户上限已到、无视口锚点的远程续接、仅账号帮助提示或普通可见候选等状态进入用户选择阶段。
- 预期行为：前三种状态分别触发现有终态、远程续接或账号帮助结束；普通可见候选必须继续由控制器的行处理链路执行。
- 实际差异：本轮为等价重构，没有线上故障；入口动作分派无法单独验证。

## 单一假设与最小修改

假设：将用户选择入口的非行处理分派移入 `UserSelectionFlow`，控制器保留原有回调，可保持候选行安全链路不变并获得独立测试。

- 新增 `UserSelectionFlow`，只消费处理上限、远程锚点和账号帮助三种既有路由。
- 普通可见候选仍返回控制器，保持身份提取、去重、屏蔽词、关注限制、OCR、几何校验、节点点击、翻页和检查点原样。
- 账号帮助的文本读取时机及下一查询/完成逻辑保持原值。

## 验证结果

- `UserSelectionFlowTest` 覆盖三种既有入口动作及普通候选不消费。
- 自动化验证：`./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug` 与 `git diff --check` 通过。
- 真机 OnePlus NE2210（`b33aa309` / Android 16）：安装更新后无障碍服务为 Bound/Enabled、`Crashed services` 为空；本轮仅做停止态服务健康确认，不启动任务、不进行页面操作、空白探测或消息发送。

## 几何与安全检查

- 未新增 Android 几何尺寸、固定 px、坐标或手势；无需新增 dp 归一化逻辑。
- 候选行始终保留节点优先、OCR 辅助、几何校验、页面确认与安全兜底顺序。
